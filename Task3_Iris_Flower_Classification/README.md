# 🌸 Iris Flower Classification

## 🌟 CodSoft Data Science Internship – Task 3

## 📌 Project Overview

This project is an Iris Flower Classification system developed using Python and Machine Learning. It classifies Iris flowers into three species: Iris-setosa, Iris-versicolor, and Iris-virginica based on flower measurements.

## 🎯 Objective

To build a Machine Learning classification model that predicts the species of Iris flowers using sepal and petal measurements.
